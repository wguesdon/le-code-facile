Apprendre dans sa langue rend les choses plus simples. Voici une sélection de ressources francophones pour aller plus loin.

## Le concept

Le monde de Python est dominé par l'anglais. Mais il existe une belle communauté francophone. Des cours, des vidéos, des livres, des forums. Tu peux progresser longtemps sans jamais quitter le français.

Cette page rassemble des points de départ fiables. La liste n'est pas exhaustive. Choisis ce qui te parle et explore à ton rythme.

## Sites web

- **OpenClassrooms**, [openclassrooms.com](https://openclassrooms.com). Plateforme française avec plusieurs cours Python gratuits. Bon pour suivre un parcours structuré.
- **Python.org**, [docs.python.org/fr/](https://docs.python.org/fr/). La documentation officielle, partiellement traduite en français. Précieuse pour vérifier le comportement exact d'une fonction.
- **Developpez.net**, [python.developpez.com](https://python.developpez.com). Communauté francophone historique avec tutoriels, forums et actualités.
- **Le site du zéro archive**, certains anciens tutoriels Python restent accessibles. Style très accessible pour débutants.
- **Real Python en français**, quelques articles traduits circulent. Cherche le titre suivi de « français » sur ton moteur de recherche.

## Vidéos

- **Docstring**, chaîne YouTube en français consacrée à Python. Format clair, projets concrets.
- **Graven**, chaîne YouTube généraliste sur la programmation, avec une bonne série Python pour débutants.
- **Le Wagon**, école de code française avec une chaîne YouTube qui couvre Python et la data.
- **Machine Learnia**, chaîne francophone qui parle de Python pour la science des données.
- **Cours en ligne de l'INRIA**, certains MOOCs Python sont disponibles gratuitement sur la plateforme FUN.

## Livres gratuits

- **« Apprendre à programmer avec Python 3 »** de Gérard Swinnen. Le classique francophone. PDF gratuit, idéal pour les débutants complets. Disponible sur [inforef.be/swi/python.htm](https://inforef.be/swi/python.htm).
- **« Apprenez à programmer en Python »** de Vincent Le Goff. Issu d'un cours OpenClassrooms, souvent disponible en PDF.
- **« Python pour les maths »** et autres livres pédagogiques produits par des enseignants français. Beaucoup sont partagés librement par des académies.

## Communautés

- **r/apprendre_le_python**, le subreddit francophone dédié à l'apprentissage de Python. Bonne ambiance, questions de débutants bienvenues.
- **r/france** ou **r/developpeurs**, pour des discussions plus larges sur la programmation en français.
- **Discord francophones**, plusieurs serveurs accueillent les débutants. Cherche « Discord Python francophone » pour trouver les serveurs actifs.
- **Developpez.net forum**, l'un des plus anciens forums francophones de développement. Encore très actif.
- **Stack Overflow en français**, [fr.stackoverflow.com](https://fr.stackoverflow.com). Pour poser une question technique précise.

## Podcasts

- **IfThisThenDev**, podcast francophone qui aborde régulièrement Python et le développement logiciel.
- **Programmons en français**, format court qui couvre des notions de programmation.

<Aside type="tip">
Le meilleur conseil reste le même. Pratique régulièrement, même cinq minutes par jour. Choisis un petit projet qui t'intéresse vraiment. La motivation vient en faisant.
</Aside>

## À retenir

- La communauté francophone Python est riche et accueillante.
- OpenClassrooms et le livre de Gérard Swinnen sont de bons points de départ gratuits.
- YouTube regorge de chaînes francophones de qualité comme Docstring et Graven.
- Les forums et subreddits francophones acceptent volontiers les questions de débutants.
- Choisis une ou deux ressources qui te plaisent et tiens bon. Mieux vaut peu mais régulier.
