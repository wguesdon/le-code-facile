Les fichiers CSV sont partout : exports de banque, tableaux Excel, données publiques. Apprenons à les lire et à en tirer quelques chiffres utiles.

## L'objectif

Nous allons traiter un petit fichier de ventes. Pour chaque ligne, on a la date, le produit, la quantité et le prix unitaire. Le script va répondre à trois questions simples. Combien de ventes au total ? Quel est le chiffre d'affaires global ? Quels sont les trois produits les plus vendus ?

## Le plan

- Créer un fichier d'exemple `ventes.csv` pour pouvoir tester.
- Ouvrir le fichier avec le module `csv` de la bibliothèque standard.
- Parcourir chaque ligne et accumuler les chiffres dans un dictionnaire.
- Trier les produits par quantité vendue.
- Afficher un petit rapport dans la console.

## Le code

D'abord, créons un fichier d'exemple. Vous pouvez copier ce contenu dans `ventes.csv` à la main, ou laisser le script suivant le faire pour vous.

```python
from pathlib import Path

EXEMPLE = """date,produit,quantite,prix
2026-01-05,pomme,3,0.80
2026-01-05,pain,1,1.20
2026-01-06,pomme,2,0.80
2026-01-06,café,1,3.50
2026-01-07,pain,2,1.20
2026-01-07,chocolat,1,2.40
2026-01-08,pomme,5,0.80
2026-01-08,café,2,3.50
2026-01-09,chocolat,3,2.40
2026-01-09,pain,1,1.20
"""

fichier = Path("ventes.csv")
if not fichier.exists():
    fichier.write_text(EXEMPLE, encoding="utf-8")
    print("Fichier d'exemple créé.")
```

<Aside type="note">
Ce bloc ne réécrit pas le fichier s'il existe déjà. C'est utile pour ne pas écraser vos propres données plus tard.
</Aside>

Maintenant, lisons ce CSV. Le module `csv.DictReader` transforme chaque ligne en dictionnaire, en utilisant la première ligne comme noms de colonnes.

```python
import csv

with fichier.open("r", encoding="utf-8") as f:
    lecteur = csv.DictReader(f)
    lignes = list(lecteur)

print(f"Nombre de lignes lues : {len(lignes)}")
```

Pour calculer le chiffre d'affaires, on multiplie quantité par prix sur chaque ligne, puis on additionne. Attention, les valeurs lues sont des chaînes de caractères. Il faut les convertir.

```python
total_ca = 0.0
for ligne in lignes:
    quantite = int(ligne["quantite"])
    prix = float(ligne["prix"])
    total_ca += quantite * prix

print(f"Chiffre d'affaires total : {total_ca:.2f} euros")
```

Pour trouver le produit le plus vendu, on additionne les quantités dans un dictionnaire. La clé est le nom du produit, la valeur est le total des quantités.

```python
par_produit = {}
for ligne in lignes:
    produit = ligne["produit"]
    quantite = int(ligne["quantite"])
    par_produit[produit] = par_produit.get(produit, 0) + quantite

print("\nQuantités par produit :")
for produit, qte in par_produit.items():
    print(f"  {produit} : {qte}")
```

<Aside type="tip">
La méthode `dict.get(cle, 0)` renvoie zéro si la clé n'existe pas encore. C'est une astuce très pratique pour faire des compteurs.
</Aside>

Trions ensuite le dictionnaire par quantité décroissante. On garde les trois premiers.

```python
classement = sorted(par_produit.items(), key=lambda paire: paire[1], reverse=True)
top_3 = classement[:3]

print("\nTop 3 des produits les plus vendus :")
for rang, (produit, qte) in enumerate(top_3, start=1):
    print(f"  {rang}. {produit} ({qte} unités)")

produit_leader = classement[0][0]
print(f"\nProduit le plus vendu : {produit_leader}")
```

Voici le script complet, prêt à exécuter.

```python
import csv
from pathlib import Path

EXEMPLE = """date,produit,quantite,prix
2026-01-05,pomme,3,0.80
2026-01-05,pain,1,1.20
2026-01-06,pomme,2,0.80
2026-01-06,café,1,3.50
2026-01-07,pain,2,1.20
2026-01-07,chocolat,1,2.40
2026-01-08,pomme,5,0.80
2026-01-08,café,2,3.50
2026-01-09,chocolat,3,2.40
2026-01-09,pain,1,1.20
"""


def preparer_fichier(chemin):
    """Crée un fichier d'exemple si nécessaire.

    Args:
        chemin (Path): Chemin du fichier à créer.
    """
    if not chemin.exists():
        chemin.write_text(EXEMPLE, encoding="utf-8")


def lire_ventes(chemin):
    """Lit le fichier CSV et renvoie une liste de dictionnaires.

    Args:
        chemin (Path): Chemin du fichier CSV.

    Returns:
        list: Une liste de lignes, chacune sous forme de dict.
    """
    with chemin.open("r", encoding="utf-8") as f:
        return list(csv.DictReader(f))


def analyser(lignes):
    """Calcule les statistiques de ventes.

    Args:
        lignes (list): Les lignes du CSV.

    Returns:
        tuple: total des lignes, chiffre d'affaires, classement par quantité.
    """
    total_ca = 0.0
    par_produit = {}
    for ligne in lignes:
        quantite = int(ligne["quantite"])
        prix = float(ligne["prix"])
        total_ca += quantite * prix
        produit = ligne["produit"]
        par_produit[produit] = par_produit.get(produit, 0) + quantite
    classement = sorted(par_produit.items(), key=lambda p: p[1], reverse=True)
    return len(lignes), total_ca, classement


def main():
    fichier = Path("ventes.csv")
    preparer_fichier(fichier)
    lignes = lire_ventes(fichier)
    nb, ca, classement = analyser(lignes)

    print(f"Nombre de ventes : {nb}")
    print(f"Chiffre d'affaires : {ca:.2f} euros")
    print(f"Produit le plus vendu : {classement[0][0]}")
    print("\nTop 3 :")
    for rang, (produit, qte) in enumerate(classement[:3], start=1):
        print(f"  {rang}. {produit} ({qte} unités)")


if __name__ == "__main__":
    main()
```

## Pour aller plus loin

- Ajouter une colonne « catégorie » et calculer le chiffre d'affaires par catégorie.

- Écrire le rapport dans un fichier `rapport.txt` au lieu de l'afficher.

## À retenir

- Le module `csv` fait partie de la bibliothèque standard, rien à installer.
- `csv.DictReader` transforme chaque ligne en dictionnaire, c'est très pratique.
- Les valeurs lues sont toujours du texte. Pensez à `int` et `float` quand il faut.
- Un dictionnaire est l'outil idéal pour additionner des choses par catégorie.
- `sorted` avec une fonction `key` permet de trier sur n'importe quel critère.
