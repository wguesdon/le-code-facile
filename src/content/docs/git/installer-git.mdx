Dans cette leçon, vous allez télécharger et installer Git sous Windows. L'installateur pose beaucoup de questions, mais ne vous inquiétez pas, nous allons les voir une par une.

## Vue d'ensemble

Git pour Windows est un installateur officiel et gratuit. Il dépose sur votre machine la commande `git`, ainsi que quelques outils complémentaires comme Git Bash. Vous n'avez rien à payer, rien à configurer en amont. Il suffit de suivre les écrans.

L'installation prend environ cinq minutes. Les questions de l'installateur ont déjà une bonne valeur par défaut. Nous allons en ajuster quelques unes pour vous éviter des surprises plus tard.

<Aside type="tip">
Si vous avez déjà fermé VSCode, c'est parfait. L'installateur peut détecter VSCode comme éditeur par défaut, et c'est plus propre si VSCode n'est pas ouvert pendant l'installation.
</Aside>

## Étapes

<Steps>

1. Ouvrez votre navigateur et allez sur la page officielle. L'adresse est [https://git-scm.com/download/win](https://git-scm.com/download/win). Le téléchargement démarre automatiquement, ou vous pouvez cliquer sur le lien proposé.

2. Le fichier téléchargé s'appelle quelque chose comme `Git-2.45.2-64-bit.exe`. Double cliquez dessus pour lancer l'installateur. Si Windows affiche un avertissement de sécurité, cliquez sur **Exécuter quand même**.

3. À l'écran de licence, lisez si vous le souhaitez, puis cliquez sur **Next**.

4. À l'écran « Select Destination Location », gardez le chemin par défaut. Cliquez sur **Next**.

5. À l'écran « Select Components », laissez les cases cochées par défaut. Cliquez sur **Next**.

6. À l'écran « Select Start Menu Folder », gardez le nom proposé. Cliquez sur **Next**.

7. À l'écran « Choosing the default editor used by Git », sélectionnez **Use Visual Studio Code as Git's default editor** si VSCode est déjà installé. Sinon, gardez Vim ou choisissez Notepad. Cliquez sur **Next**.

8. À l'écran « Adjusting the name of the initial branch in new repositories », choisissez **Override the default branch name for new repositories** et laissez la valeur `main`. C'est le nom moderne et standard. Cliquez sur **Next**.

9. À l'écran « Adjusting your PATH environment », choisissez **Git from the command line and also from 3rd-party software**. C'est l'option du milieu, et c'est la recommandation officielle. Elle permet d'utiliser `git` dans Anaconda Prompt et PowerShell. Cliquez sur **Next**.

10. À l'écran « Choosing the SSH executable », gardez **Use bundled OpenSSH**. Cliquez sur **Next**.

11. À l'écran « Choosing HTTPS transport backend », gardez **Use the OpenSSL library**. Cliquez sur **Next**.

12. À l'écran « Configuring the line ending conversions », choisissez **Checkout Windows-style, commit Unix-style line endings**. C'est important sous Windows pour éviter des conflits avec d'autres systèmes. Cliquez sur **Next**.

13. À l'écran « Configuring the terminal emulator », gardez **Use MinTTY**. Cliquez sur **Next**.

14. À l'écran « Choose the default behavior of `git pull` », gardez **Default (fast-forward or merge)**. Cliquez sur **Next**.

15. À l'écran « Choose a credential helper », choisissez **Git Credential Manager**. Cet outil va stocker vos identifiants GitHub pour vous éviter de les retaper à chaque fois. Cliquez sur **Next**.

16. À l'écran « Configuring extra options », laissez les cases par défaut. Cliquez sur **Next**.

17. À l'écran « Configuring experimental options », ne cochez rien. Cliquez sur **Install**.

18. L'installation prend une ou deux minutes. Quand elle se termine, décochez les cases qui proposent d'ouvrir des notes de version, et cliquez sur **Finish**.

</Steps>

<Aside type="note">
Si vous vous êtes trompé sur une option, ce n'est pas grave. Vous pouvez relancer l'installateur et corriger. Toutes les options sont aussi modifiables après coup avec des commandes Git.
</Aside>

## Exemple

Pour vérifier que Git est bien installé, faisons un test rapide.

<Steps>

1. Fermez toutes les fenêtres d'Anaconda Prompt et de PowerShell qui étaient ouvertes avant l'installation. Les nouvelles variables d'environnement ne s'appliquent qu'aux fenêtres ouvertes après.

2. Ouvrez une **nouvelle** fenêtre d'Anaconda Prompt depuis le menu Démarrer.

3. Tapez la commande suivante et appuyez sur Entrée.

</Steps>

```powershell
git --version
```

Vous devriez voir quelque chose comme ceci.

```
# Sortie:
git version 2.45.2.windows.1
```

Le numéro exact peut varier. L'important, c'est que la commande renvoie une version de Git sans erreur.

Vous pouvez aussi tester dans PowerShell, si vous préférez. La commande est la même.

```powershell
git --version
```

## Problèmes courants

- **`git n'est pas reconnu comme une commande interne ou externe`.** Vous avez ouvert votre fenêtre de terminal avant d'installer Git. Fermez la et ouvrez une nouvelle fenêtre. Si le problème persiste, c'est que l'option PATH n'a pas été choisie. Relancez l'installateur et sélectionnez « Git from the command line and also from 3rd-party software ».
- **L'installateur est bloqué par Windows Defender SmartScreen.** Cliquez sur « Informations complémentaires », puis sur « Exécuter quand même ». Le fichier provient bien du projet Git officiel.
- **Vous voyez beaucoup d'écrans inconnus.** C'est normal. Git est très configurable. Suivez les choix recommandés ci-dessus, et vous serez tranquille.

## À retenir

- Git pour Windows se télécharge sur [https://git-scm.com/download/win](https://git-scm.com/download/win).
- Pendant l'installation, choisissez VSCode comme éditeur, `main` comme branche par défaut, et Git Credential Manager pour les identifiants.
- L'option PATH du milieu permet d'utiliser `git` partout, y compris dans Anaconda Prompt.
- La commande `git --version` confirme que tout est en place.
- Une fenêtre de terminal ouverte avant l'installation ne voit pas Git. Ouvrez une nouvelle fenêtre.
