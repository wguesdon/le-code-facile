Dans cette leçon, vous allez découvrir les trois outils que nous installerons ensemble pour démarrer avec Python.

## Vue d'ensemble

Pour écrire votre premier programme Python, vous avez besoin de trois choses. Nous allons les installer une par une. Pas de panique, chaque étape est simple.

Voici une analogie pour bien comprendre.

- **Python**, c'est la langue dans laquelle vous allez parler à l'ordinateur.
- **Anaconda**, c'est la boîte à outils qui installe Python proprement et vous évite bien des soucis.
- **VSCode**, c'est l'atelier où vous allez écrire votre code, confortablement installé.

Vous n'avez pas besoin de comprendre tous les détails maintenant. Le but de cette section, c'est juste de poser le décor.

## Python, le langage

Python est un langage de programmation. Vous écrivez des instructions en texte, et l'ordinateur les exécute. Le mot « Python » désigne à la fois le langage et le petit programme qui lit votre code.

Python est connu pour sa lisibilité. C'est l'une des raisons pour lesquelles il est très utilisé pour débuter.

## Anaconda, la boîte à outils

Anaconda est une distribution. Une distribution, c'est une collection de logiciels prêts à l'emploi, livrés ensemble.

Quand vous installez Anaconda, vous obtenez Python, plus des centaines de paquets utiles, plus deux petits programmes très pratiques. Le premier s'appelle Anaconda Navigator. Le second s'appelle Anaconda Prompt. Nous y reviendrons.

Pour un grand débutant sous Windows, Anaconda est la voie la plus simple. L'installation est en un clic, et tout fonctionne du premier coup.

## VSCode, l'atelier

VSCode, ou Visual Studio Code, est un éditeur de code. C'est un logiciel qui ressemble à un traitement de texte, mais conçu pour écrire du code.

VSCode est gratuit, léger, et très populaire. Il fonctionne avec presque tous les langages, y compris Python.

## Pourquoi cette combinaison

Cette combinaison, Python plus Anaconda plus VSCode, est très accueillante pour les débutants. Les raisons sont simples.

- L'installation est guidée, étape par étape.
- Tout est gratuit.
- Vous trouverez beaucoup d'aide en ligne, car c'est une combinaison très répandue.
- Si quelque chose ne marche pas, vous pouvez désinstaller Anaconda sans casser votre ordinateur.

## Et uv, alors ?

Vous entendrez peut-être parler de **uv**. C'est un autre outil pour gérer Python, plus moderne et plus rapide qu'Anaconda. Il est très bien, mais un peu plus technique pour commencer.

Nous le présentons en bonus à la fin de cette section. Si vous débutez vraiment, restez sur Anaconda pour l'instant. Vous pourrez toujours essayer uv plus tard.

## À retenir

- Python est le langage, Anaconda est la boîte à outils, VSCode est l'atelier.
- Anaconda installe Python proprement sous Windows, sans prise de tête.
- VSCode est l'éditeur où vous allez taper votre code.
- uv est une alternative moderne, optionnelle, que nous verrons en bonus.
- Vous n'avez besoin de rien d'autre pour commencer.
