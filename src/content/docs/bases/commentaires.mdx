Un bon code se relit facilement, des mois plus tard. Les commentaires et la mise en forme y contribuent beaucoup.

## Le concept

Un commentaire est un texte ignoré par Python. Il sert à expliquer le code aux humains qui le liront. En Python, un commentaire commence par le caractère `#`.

```python
# Calcule le prix total avec la TVA
prix_ht = 100
tva = 0.20
prix_ttc = prix_ht * (1 + tva)

print(prix_ttc)
# Sortie: 120.0
```

Tout ce qui suit le `#` sur la même ligne est ignoré.

```python
age = 30  # âge du client
```

## Pourquoi commenter

Un bon commentaire répond à la question : pourquoi ce code existe. Il n'a pas besoin de répéter ce que le code dit déjà.

### Mauvais commentaire

```python
# On ajoute 1 à age
age = age + 1
```

Ce commentaire dit la même chose que le code. Il n'apporte rien.

### Bon commentaire

```python
# On fête l'anniversaire du client
age = age + 1
```

Ce commentaire explique l'intention. Il aide à comprendre le sens du programme.

<Aside type="tip">
Si vous hésitez à mettre un commentaire, demandez vous : est ce que le code suffit à se comprendre tout seul ? Si oui, pas de commentaire. Si non, écrivez ce que le code ne dit pas.
</Aside>

## L'indentation en Python

En Python, l'indentation n'est pas seulement esthétique. Elle a un sens. Un bloc de code se reconnaît à son décalage vers la droite.

La convention est d'utiliser 4 espaces par niveau.

```python
age = 20

if age >= 18:
    print("Bienvenue.")
    print("Tu es majeur.")
```

Mélanger des espaces et des tabulations crée des erreurs difficiles à voir. Restez avec 4 espaces partout.

## Les lignes vides

Les lignes vides aident à séparer les sections logiques d'un programme. Elles facilitent la lecture.

```python
# Informations client
prenom = "Alice"
age = 30

# Informations panier
prix = 12.50
quantite = 3

# Calcul du total
total = prix * quantite
print(total)
# Sortie: 37.5
```

## Nommer ses variables

Un bon nom de variable vaut souvent mieux qu'un commentaire. Préférez un nom clair à une variable cryptique suivie d'une explication.

```python
# Pas clair
x = 12.50
y = 3
z = x * y

# Clair
prix_unitaire = 12.50
quantite = 3
prix_total = prix_unitaire * quantite
```

## Exemple avant et après

Voici un petit programme peu lisible.

```python
a = "Alice"
b = 30
c = 12.50
d = 3
e = c * d
print(a, b, e)
```

Et voici le même programme, mieux écrit.

```python
# Données du client
prenom = "Alice"
age = 30

# Panier
prix_unitaire = 12.50
quantite = 3

# Total à payer
prix_total = prix_unitaire * quantite

print(prenom, age, prix_total)
# Sortie: Alice 30 37.5
```

Le second programme se comprend tout seul. Les commentaires et les bons noms font la différence.

## En pratique

Quelques règles simples pour garder un code propre :

- Choisir des noms de variables qui décrivent ce qu'elles contiennent.
- Mettre 4 espaces pour chaque niveau d'indentation.
- Séparer les sections par des lignes vides.
- Écrire un commentaire quand l'intention n'est pas évidente.
- Éviter les commentaires qui répètent le code.

<Aside type="note">
Le code que vous écrivez aujourd'hui sera relu par vous demain. Soyez gentil avec votre futur vous.
</Aside>

## À retenir

- Un commentaire commence par `#` et est ignoré par Python.
- Un bon commentaire explique pourquoi, pas ce que fait le code.
- L'indentation se fait avec 4 espaces. Elle est obligatoire en Python.
- Les lignes vides séparent les sections logiques.
- Un nom de variable clair vaut souvent mieux qu'un commentaire.
