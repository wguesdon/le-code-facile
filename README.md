# Le Code Facile

> La programmation à la portée de tous.

Site gratuit en français pour apprendre à coder à partir de zéro. Pas de prérequis.

## Développer en local

```bash
npm install
npm run dev
```

Puis ouvrir `http://localhost:4321/le-code-facile/`.

## Construire

```bash
npm run build
```

Le site statique est produit dans `dist/`.

## Déploiement

Le workflow `.github/workflows/deploy.yml` publie le site sur GitHub Pages à chaque push sur `main`.
URL : https://wguesdon.github.io/le-code-facile/
